# Urban-Crash-Risk-Radar

Problem Statement

Car crashes impose substantial social, health, and economic costs. Transportation agencies and city governments need early signals of where and when risk is rising so they can target enforcement, signage, roadway design, and outreach.

Goal: Build a system that continuously ingests city crash data, enriches with weather/time features, predicts crash risk per grid cell per hour, and publishes a web map for comparison across five cities.
